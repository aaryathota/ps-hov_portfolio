Page Headline
Builder. Operator. Founder.
Sub-headline:
Here is my story and what I am building.

My Story
P.Sonkar House Of Ventures did not come together through a single plan. It came together through years of working on things I genuinely believed needed to exist, starting from scratch, figuring things out on the ground, and building across areas I found myself drawn to.
Over time, what started as individual projects began to take shape as a connected ecosystem. P.Sonkar House Of Ventures is the formal structure that holds all of it together. It is the parent entity behind every venture I build and every collaboration I am part of.

How I Work
Start With Clarity
Every venture I work on begins with a clear understanding of the problem being solved, who it is being solved for, and whether there is a sustainable model behind it. Clarity before action, always.
Stay Close to the Work
I stay operationally close to what I build. Not from a distance. I am inside the decisions, the conversations, and the details that actually determine whether something works or not.
Build Systems, Not Dependencies
The goal is always to build something that does not depend entirely on me. Systems and teams are built alongside what we are building, not after it.

What Drives the Portfolio
Each venture in this ecosystem exists because there was a real gap worth addressing. The sectors vary but the reasoning is consistent: a problem that is large enough, a solution that is practical, and a model that can be made to work.

In My Own Words

"I did not set out to build a venture studio. I set out to work on things I believed needed to exist. This is what that looks like so far.
Along the way, I also built a network of people, businesses, and collaborations that became just as much a part of this ecosystem as the ventures I own. The Collaborated Services side of this is not separate from what I do. It is a reflection of the relationships and partnerships I have built over time for responsible and quality work getting delivered."

[ ADMIN PORTAL MODULE SPECIFICATION ]
Admin Portal: Full Module Specification
Access:
Single login for Pratap only. Email and password authentication. All actions logged with timestamp. No public registration.

Module 1: In-House Ventures Manager
Purpose:
Manage all venture cards displayed under the In-House Ventures toggle on the Ventures page.
Actions Available:
	•	Add new venture card
	•	Edit any field on an existing card
	•	Archive or permanently delete a card
	•	Toggle card visibility: Live or Hidden (hidden cards are not shown on the site but are not deleted)
	•	Drag-and-drop reorder of cards
	•	Preview how a card will appear on the site before publishing
Fields per Card:
	•	Image upload (recommended size and format guidance shown in admin)
	•	Company Name (text field, required)
	•	Company Description (text area, 2 to 3 lines recommended, required)
	•	Website URL (text field, optional)
	•	Website Link Toggle: On or Off (when Off, the Visit Website button does not appear on the card)

Module 2: Collaborated Services Manager
Purpose:
Manage all service cards displayed under the Collaborated Services toggle on the Ventures page.
Actions Available:
	•	Add new service card
	•	Edit any field on an existing card
	•	Archive or permanently delete a card
	•	Toggle card visibility: Live or Hidden
	•	Drag-and-drop reorder of cards
	•	Preview before publishing
Fields per Card:
	•	Image upload (required)
	•	Service Name (text field, required)
	•	Service Description (text area, 2 to 3 lines recommended, required)
	•	WhatsApp Number (text field: uses global number from Site Settings by default, can be overridden per card)
	•	WhatsApp Pre-fill Message: auto-generated as 'Hi, I am interested in [Service Name]. Can we connect?' using the Service Name field. Admin can optionally customise this message per card.

Module 3: Get Involved Form Responses
Purpose:
View and manage all form submissions from the Get Involved page.
Actions Available:
	•	View all submissions in a table with columns: Name, Email, Phone, Intent (Invest / Work / Grow), Date Submitted
	•	Click any row to expand and see all fields submitted for that entry
	•	Mark submission as: New, Reviewed, Follow-Up Pending, Closed
	•	Export all submissions as CSV
	•	Filter submissions by Intent type (Invest / Work / Grow) and by status
Notification Setting:
	•	Option to receive an email notification to admin email each time a new form is submitted

Module 4: Ventures Multi-Select List (for Work form)
Purpose:
Manage the list of ventures that appears in the multi-select field on the Work section of the Get Involved form.
Actions Available:
	•	Add venture name to the list
	•	Remove venture name from the list
	•	Reorder the list
Note:
DEV NOTE: This list should reflect currently active In-House Ventures. Admin updates this manually when ventures are added or changed. It does not auto-sync from Module 1.

Module 5: Site-Wide Settings
Purpose:
Manage global settings that apply across the entire website.
Fields:
	•	Primary WhatsApp Number (used as default for Collaborated Services cards and the WhatsApp button in footer)
	•	Primary Email Address
	•	LinkedIn URL
	•	Instagram Handle
	•	Twitter / X Handle
	•	Footer Legal Year (auto-updates or manual)
	•	Homepage Venture Snapshot: select which 3 to 4 venture cards from Module 1 appear in the Ventures Snapshot section on the homepage
